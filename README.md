# Bootstrap Practice

A collection of Bootstrap practice pages and a small adventure-themed website.

## Folders

- [`basic/`](basic/) — Bootstrap component and layout examples.
- [`project adventure/`](project%20adventure/) — adventure website pages, stylesheets, scripts, and images.

## Pages to start with

- [Basic layout](basic/basic.html)
- [Alerts](basic/alerts.html)
- [Tables](basic/table.html)
- [Adventure website](project%20adventure/index.html)

Open an HTML file in a browser to view it. The pages load Bootstrap from a CDN, so an internet connection is needed for Bootstrap styling and scripts.
